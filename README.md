ApexPlanet Internship - Task 1: Basics of Web Development
This repository contains the source code and implementation for Task 1 of the 45-day Web Development internship program. The goal of this task is to establish a strong foundation in core web technologies by building a structured, styled, and interactive webpage from scratch.

Tasks & Objectives Covered
HTML Structure: Created a well-structured webpage using fundamental HTML elements, including headings, paragraphs, images, and hyperlinks.

CSS Styling: Applied custom styling using CSS to enhance visual appeal, including colors, typography, spacing, and layout adjustments.

JavaScript Interactivity: Implemented basic client-side scripting by adding an interactive button that triggers a JavaScript alert message when clicked.

Technologies Used
HTML5
CSS3
JavaScript
